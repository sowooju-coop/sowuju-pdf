# 로드맵

## 0.1 기본 틀
- [x] Electron + React + MuPDF.js 구조
- [x] PDF 열기·보기·저장, 암호 PDF
- [x] 페이지 회전·삭제·순서 바꾸기
- [x] 인쇄 (범위·품질 선택, 운영체제 인쇄 창)
- [x] Windows 설치 파일 자동 빌드

## 0.2 웹 버전 기능 옮기기
- [x] PDF·사진 합치기, 빈 쪽 넣기, 파일에서 쪽 넣기, 복제, 고른 쪽만 새 PDF로 저장
- [x] 한눈에 보기: 모든 쪽을 바둑판으로 펼쳐 끌어서 순서 바꾸기, 크기 조절
- [x] 쪽 목록: 끌어서 순서 바꾸기(따라오는 표시·놓일 자리 선·자동 넘김·Esc 취소), 오른쪽 클릭 메뉴, 쪽 사이 + 단추, Delete 키, 파일 끌어다 넣기
- [x] 글자 추가
- [x] 형광펜, 펜, 체크 표시, 네모·동그라미·선·화살표
- [x] 서명 그리기·사진에서 가져오기, 직인 만들기(네모·동그라미)·사진에서 가져오기(흰 배경 지우기·빨간색만 남기기), 보관함
- [x] 서명·직인 놓기, 끌어서 옮기기, 크기 조절, 적용해서 고정 (저장·인쇄 때 자동 적용)
- [x] 날짜 넣기
- [x] 실행 취소·다시 실행

## 0.3 티 안 나는 글자 수정 (MuPDF 핵심)
- [x] 글자 단위 정확한 위치 읽기 (structured text)
- [x] 원래 글자를 파일에서 진짜로 지우고(redaction) 같은 자리에 새 글자 쓰기
- [x] 원래 글꼴에 맞춰 고딕·명조, 크기, 자간, 색 자동 맞춤
- [x] 바뀐 글자만 다시 쓰기, 길이가 달라지면 줄 끝까지 다시 써서 자연스럽게 밀기
- [x] 실행 취소·다시 실행
- [ ] 여러 줄 문단 고치기
- [x] 개인정보 완전 삭제 도구 (페이지를 이미지로 바꾸지 않고)
- [x] 한글(HWP)·워드에서 만든 문서는 문서 안의 원래 글꼴을 그대로 써서 고치기

## 디자인 (시안 확정)
- [x] 시작 화면: 바로 시작하기, 최근 문서, 끌어다 놓기
- [x] 편집 화면: 한 줄 도구 막대, 쪽 목록, 오른쪽 속성 패널, 떠 있는 쪽·확대 막대
- [x] 글자 수정: 글자 위 작은 도구 막대, 고치는 글자 비교, 이번에 고친 곳 목록
- [x] 쉬운 모드: 큰 단추, 단계 표시, 글씨 크기 3단계
- [x] 저장하지 않고 닫을 때 확인
